10. **Robustness**

Example 1 (Complex Filtering on Two Properties in One Submodel - Mass & Chemistry):
Natural Language Input: Find vehicles with solid-state battery chemistry and battery mass greater than 600 kg.
SPARQL Query:
PREFIX bp: <http://edp4e.org#>
PREFIX xsd: <http://www.w3.org/2001/XMLSchema#>
SELECT ?vehicle ?chemistry (CONCAT(STR(?mass), " ", COALESCE(?massUnit, "")) AS ?Batterymass)
WHERE {
  ?vehicle bp:hasBDS ?submodel .
  ?submodel bp:hasProperty ?chemProp, ?massProp .
  ?chemProp bp:idShort "BatteryChemistry" ; bp:value ?chemistry .
  ?massProp bp:idShort "BatteryMass" ; bp:value ?rawMass .
  OPTIONAL { ?massProp bp:description ?massUnit }
  BIND(xsd:integer(?rawMass) AS ?mass)
  FILTER(?chemistry = "Solid-State" && ?mass > 600)
}

Example 3 (Complex Calculation and Mismatch Detection):
Natural Language Input: Find vehicles where the rated capacity differs from the certified usable energy by more than 5%.
SPARQL Query:
PREFIX bp: <http://edp4e.org#>
PREFIX xsd: <http://www.w3.org/2001/XMLSchema#>
SELECT ?vehicle (CONCAT(STR(?ratedCapacity), " ", COALESCE(?ratedUnit, "")) AS ?RatedCapacity) (CONCAT(STR(?nominalCapacity), " ", COALESCE(?nominalUnit, "")) AS ?NominalCapacity) ?diff
WHERE {
  ?vehicle bp:hasSP ?sp .
  ?sp bp:hasProperty ?ratedProp .
  ?ratedProp bp:idShort "RatedCapacity" ; bp:value ?rawRated .
  OPTIONAL { ?ratedProp bp:description ?ratedUnit }
  ?vehicle bp:hasBDS ?bds .
  ?bds bp:hasProperty ?nomProp .
  ?nomProp bp:idShort "CertifiedUsableBatteryEnergy" ; bp:value ?rawNominal .
  OPTIONAL { ?nomProp bp:description ?nominalUnit }
  BIND(xsd:decimal(?rawRated) AS ?ratedCapacity)
  BIND(xsd:decimal(?rawNominal) AS ?nominalCapacity)
  BIND(ABS(?ratedCapacity - ?nominalCapacity) / ?nominalCapacity AS ?diff)
  FILTER(?diff > 0.05)
}

Example 4 (Filtering on Date Fields):
Natural Language Input: Find vehicles where the manufacturing date is strictly before the battery delivery date.
SPARQL Query:
PREFIX bp: <http://edp4e.org#>
PREFIX xsd: <http://www.w3.org/2001/XMLSchema#>
SELECT ?vehicle ?MfgDate ?DelivDate
WHERE {
  ?vehicle bp:hasMFG ?mfg .
  ?mfg bp:hasProperty ?mfgProp .
  ?mfgProp bp:idShort "ManufacturingDate" ; bp:value ?manufacturingDateRaw .
  ?vehicle bp:hasCRM ?crm .
  ?crm bp:hasProperty ?crmProp .
  ?crmProp bp:idShort "DateOfBatteryDelivery" ; bp:value ?deliveryDateRaw .
  FILTER(xsd:date(?manufacturingDateRaw) < xsd:date(?deliveryDateRaw))
  BIND(STR(xsd:date(?manufacturingDateRaw)) AS ?MfgDate)
  BIND(STR(xsd:date(?deliveryDateRaw)) AS ?DelivDate)
}
